# Get Your Scripts From The CFX Portal

The Meteo Studios scripts are NOT included in this download. You download them
straight from your CFX account (the same one you bought them with).

## How to install

1. Go to the CFX portal: https://portal.cfx.re/
2. Sign in with the CFX account you used to purchase.
3.  Download the **Meteo scripts bundle**
4. Drop that **[meteostudios]** folder, inside
   `server-data/resources/`
## Notes

- Always download the latest version from the portal to match this build.
- Need help? Docs: https://docs.meteostudios.net/packages/meteo-v2-package  -  Discord: https://discord.gg/P5cPsVTNZf
