# Get The Prompt Studio Maps From The CFX Portal

The Prompt Studio maps are NOT included in this download.

The Meteo V2 maps package is a collaboration between Meteo Studios and Prompt
Studio. Get it here: https://store.prompt-mods.com/store/package/7718215

**The package locations are made for these maps.** Without them, police, EMS,
jail, casino and other spots will sit in empty buildings or open ground.

## How to install

1. Go to the CFX portal: https://portal.cfx.re/
2. Sign in with the CFX account you bought the Prompt Studio maps with.
3. Download these 3 parts. You need all 3:

- Prompt's - Meteo V2 (Part 1)
- Prompt's - Meteo V2 (Part 2)
- Prompt's - Meteo V2 (Part 3)

4. Drop all 3 into this **[prompt-maps]** folder
   (`resources/[assets]/[prompt-maps]/`) and restart the server.

Full guide: https://docs.meteostudios.net/packages/meteo-v2-package/installation-guide#prompt-studio-maps
