# Get The Prompt Studio Maps From The CFX Portal

The Prompt Studio maps are NOT included in this download.

The Meteo V2 maps package is a collaboration between Meteo Studios and Prompt
Studio. Get it here: https://store.prompt-mods.com/store/package/7718215

**The package locations are made for these maps.** Without them, police, EMS,
jail, casino and other spots will sit in empty buildings or open ground.

## How to install

1. Go to the CFX portal: https://portal.cfx.re/
2. Sign in with the CFX account you bought the Prompt Studio maps with.
3. Download each map below - every map is its own download.
4. Drop each map folder inside this **[prompt-maps]** folder
   (`resources/[assets]/[prompt-maps]/`).
5. Stop the server and run `tools/meteo-promptmaps.bat` in your server folder.
   It applies the Meteo fixes to the maps. Run it again after every map update.

## Sandy map data

The Sandy maps share one extra folder, **cfx_prompt_sandy_mapdata**. It is not on
the CFX portal: Prompt's tool makes it for the exact Sandy maps you own.

1. Start the server once with your Sandy maps in place.
2. The console prints a link to the Prompt map data tool - make the map data there.
3. Put the **cfx_prompt_sandy_mapdata** folder in this folder and restart.

Make it again whenever you add or remove a Sandy map.
